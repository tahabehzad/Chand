# Historical Reports & Legacy Audit Archive

این پوشه شامل گزارش‌ها، پلن‌ها و مستندات حسابرسی فازهای قبلی پروژه (فازهای ۱ و ۲ - پیش‌استخدام و محاسبات قانون کار ۱۴۰۴) است که توسط ایجنت‌های پیشین ایجاد شده بودند.

با پذیرش رسمی **ADR-013** و **ADR-014** توسط مالک پروژه، دامنه محصول فعال به **«ابزار هوشمند تحلیل رزومه و تخمین حقوق ماهانه در بازار کار ایران»** تغییر یافته است. این اسناد صرفاً جهت ردیابی تاریخچه، حفظ سوابق و عدم اتلاف مستندات تاریخی به این پوشه منتقل شده‌اند و مبنای توسعه فعلی سیستم نیستند.
